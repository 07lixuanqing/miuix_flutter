# 强调色层次

`MiuixAccentLayers` 是可选的 `ThemeExtension`，提供配对的导航、选中、淡衬底、文字、边界、轨道和禁用角色。没有扩展的既有调用保留默认行为；控件显式颜色参数优先。

主按钮继续使用 `ColorScheme.primary/onPrimary`。导航和筛选不要直接复用这对实色按钮角色：透明镜片与文字分别取 `navigationFill/navigationForeground`，普通选择取 `selectionFill/selectionForeground`，说明背景取更轻的 `subtleFill/subtleForeground`。`navigationPanelOpacity` 控制面板实体遮罩，和镜片的染色浓度、背景模糊分别处理。

宿主应先针对自己的真实画布完成配对，再一次注入全部 `MiuixAccentLayers.names`。本库不选择幸运色、壁纸、账号或应用偏好，不要求使用方接入指定的取色算法。主色和报告色块可保留原始 RGB，显示前景按实际背景校准可读性。

当前接线覆盖悬浮底栏、普通及展开侧栏、芯片、分段选择、页内 Tab 和按钮禁用态。主按钮可用态不受层次表淡化。文字保持独立前景，不与镜片 Alpha 相乘。改色不改变手势回调、目的地或业务状态。

底栏按实际标签、最大字重和系统文字缩放测量共同高度，长标签自然换行，不再通过隐藏英文、固定单行或 FittedBox 缩小字体。普通字号仍保留原有尺寸基线；200% 字号和长中文会增加必要高度，目的地保持等宽。`layoutLabel` 参数保留调用兼容，实际布局以可读标签为准。

材质透明度和明度属于项目视觉校准值，不是厂商公布的设计参数。复杂背景和高对比模式应优先保证可读性；变通透不等于对所有颜色机械使用同一个 Alpha。

提供层次扩展时，`navigationPanelOpacity` 同时是导航可读性所需的最低遮罩。控件先解析玻璃档位，再保留这个下限，不会在 `MiuixGlass` 内第二次降低透明度；模糊仍随档位变化。组件显式 `backgroundOpacity` 保留覆盖优先级，未安装扩展的旧调用维持原有五档行为。

可额外提供 `colors['navigationUnselectedForeground']`，用于正常可用的未选导航项。该项不是禁用文字，不额外降低Alpha；旧宿主没有此项时沿原语义颜色。复制和主题插值会保留可选角色，单端缺失不会使文字从透明淡入。导航选中镜片应明显区别于普通画布，不能仅追求文字数学对比而忽略选中状态是否可辨。

分段选择在父宽度不足时自动等分，过窄时纵向排列；默认高度按完整标签和系统字号测量，不用省略号隐藏选项。显式 source／零高度覆盖仍保留原兼容契约，调用方需要为其显式尺寸负责。导航测试注册从原 9046 行文件按导航栈、表面、侧栏和输入拆分，原入口、名称与注册顺序保留。

普通侧栏与可展开侧栏的折叠、展开状态也使用可选未选前景，不再对已校准颜色叠乘旧的40%透明度。无扩展与source兼容模式保留原契约。回归读取实际RenderParagraph颜色，覆盖明暗和200%字号。
