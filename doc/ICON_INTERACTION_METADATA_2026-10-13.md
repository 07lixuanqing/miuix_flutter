# 图标交互信号

`MiuixIconInteraction` 向后代提供 enabled、pressed、selected 和 activation。
图标按钮、可点击卡片、普通按钮、底栏与侧栏发布对应状态。activation 仅在手势确认或键盘/无障碍操作成功触发时递增，取消手势不递增。

这是应用图标动效的可选输入；组件库不增加默认图标动画，不改变布局、点击区域、语义、回调次数或原有控件反馈。应用可在 MiuixIconTheme.builder 内监听最近的信号，自行应用绘制变换，并遵循减少动态效果与 TickerMode。

情侣记在三种风格中共用短促点击、选中和页面入场反馈，运动时长与曲线是项目设定值，不宣称为小米官方参数。库测试检查确认/取消事件和布局；交付执行完整 Release 周期，Android 本地证书仅用于测试分发。
